# Void SDDM Theme

Minimal and clean SDDM login theme with customizable appearance and smooth animations.

## Keyboard Navigation

- **Arrow Keys**: Navigate between selectors and options
- **Enter**: Activate selected option or authenticate
- **F10**: Suspend system
- **F11**: Shutdown system
- **F12**: Restart system

## Requirements

- SDDM (Simple Desktop Display Manager)
- Qt 6
